# margin-maintenance-tracker

台股融資維持率查詢工具。輸入單一股票代號，自動抓取現價（盤中即時 / 盤後收盤）與融資餘額，並以「N 日均價」推估融資成本，計算並顯示該股「現價對應的融資維持率」，同時提供選配的產業合計維持率功能。

---

## 功能簡介

- **股票搜尋**：輸入 4 碼股票代號（例：`2330`），可調整 N 值（預設 20）
- **現價抓取**：交易時段（09:00–13:30 台北時間）顯示「即時」成交價；非交易時段顯示「收盤」價；當盤無成交時以中間價/昨收 fallback
- **融資成本（推估）**：採**加權平均成本法**（與券商看盤軟體同法，已反向工程並對答案驗證，見 `docs/margin-cost-algorithm.md`）——新融資買進以當日收盤入帳、逐日滾動：`成本[t] = 成本[t-1] + (今日融資買進 / 今日融資餘額) × (收盤 − 成本[t-1])`。以 `app/data/margin_cost_seed.json`（2026-07-17 券商級成本，1744 檔）為種子，每日用 TWSE/TPEx 融資資料自動滾動更新。無種子的標的退回 **N 日均價**簡易估計（介面會標示）
- **N 日均價**：最近 N 個有效交易日收盤價算術平均，作為無成本種子時的 fallback 與參考值
- **融資餘額**：顯示最近一交易日融資餘額張數（僅供顯示與產業合計用，不影響個股維持率公式）
- **維持率計算**：`維持率 = 現價 / (N 日均價 × 0.6) × 100`（融資成數固定 0.6），並依門檻標示警戒色：
  - `< 130%`：danger（達整戶追繳線）
  - `130% ~ 166.67%`：warn（虧損中未追繳）
  - `>= 166.67%`：safe（≥ 融資成數 0.6 的自然回本基準 1/0.6）
- **容錯降級**：任一子資料（現價 / 均價 / 融資餘額）失敗只會該欄位顯示「無資料」或「無法計算」，不影響其餘欄位，整體查詢永不回 500
- **產業合計維持率（選配）**：`Σ(收盤價×資餘) / Σ(N日均價推估×資餘×0.6) × 100`，上市/上櫃分開計算
- **全市場維持率警示清單**（頁面下方區塊，端點 `GET /api/alerts?n=20`）：一次掃描**全市場有融資餘額**的上市＋上櫃股票（約 1800 檔），計算每檔維持率並依「由低到高」排序，分區段色標（`<130` 紅 / `130~150` 橘 / `150~166.67` 黃 / `≥166.67` 綠），快速找出「即將跌破追繳線」的標的。前端可依門檻（<130 / <150 / <200 / 全部）就地篩選。
  - **效率**：以「全市場單日收盤」批次端點抓 N 天即得每檔 N 日均價（不逐檔抓），首次掃描約 10~40 秒，歷史收盤快取後再掃更快；整份結果後端快取 300 秒
  - **除權/分割還原**：台股單日漲跌幅上限 ±10%，若某檔近 N 日收盤出現 >35% 跳空（分割/反分割/除權），自動只取「事件後」連續段計算均價（標記「＊還原」），避免未還原價混算出假維持率

> **免責說明**：免費融資融券資料僅提供「張數」，無「金額」，融資成本一律以 N 日均價推估，**非真實融資成本**，僅供參考。

## 開發端啟動（macOS / Linux / Windows 開發模式皆適用）

### 方式一：pip

```bash
pip install -r requirements.txt
python run.py
```

### 方式二：uv

```bash
uv run run.py
```

啟動後開啟瀏覽器：

```
http://127.0.0.1:8000
```

在查詢框輸入股票代號（如 `2330`）即可查詢。本工具**需要連網**，即時向 TWSE（證交所）、TPEx（櫃買中心）、Yahoo Finance 抓取資料，不使用離線快取。

## 資料來源與免責聲明

- 現價：TWSE MIS 即時報價 / 收盤價
- 歷史收盤序列：TWSE `STOCK_DAY`（上市）/ TPEx `tradingStock`（上櫃），官方來源失敗時自動 fallback 至 Yahoo Finance
- 融資餘額：TWSE `MI_MARGN`（上市）/ TPEx 融資融券頁（上櫃）
- 警示清單全市場單日收盤：TWSE `MI_INDEX`（上市）/ TPEx `dailyQuotes`（上櫃）
- 融資成本以「N 日均價」推估，**非實際融資成本**，僅供參考，實際維持率請以券商對帳單為準
- 本工具不儲存、不快取任何個資或帳戶資料，僅即時查詢公開市場資訊

## 已知限制

- 上櫃個股融資餘額資料來源穩定性略低於上市，若當日無法取得會顯示「無資料」，不影響現價與 N 日均價欄位
- 需要連網才能查詢；離線環境無法使用
- 91 開頭代碼（權證/牛熊證）不支援查詢
- 產業合計維持率（選配功能）於成分股數量龐大時查詢耗時較長，回應中會標註排除筆數與耗時提示
- N 值上限為 250（歷史資料筆數上限），超出範圍會自動限制在合理區間內
