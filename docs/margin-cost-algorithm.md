# 融資成本（推估）算法 — 反向工程結果

> 來源：由使用者提供的 `融資成本.xlsx`（券商等級資料，2025-01-17 ~ 2026-07-17，2032 檔）
> 反推，並用 TWSE/TPEx 每日融資資料對答案驗證。2026-07-17 定案。

## 核心遞迴公式（已驗證）

```
融資成本[t] = ( 融資成本[t-1] × (今日融資餘額 − 今日融資買進)
              + 今日收盤價 × 今日融資買進 )  ÷  今日融資餘額
```

等價寫法（權重形式）：
```
w[t] = 今日融資買進 / 今日融資餘額
融資成本[t] = 融資成本[t-1] + w[t] × (今日收盤價 − 融資成本[t-1])
```

## 三個關鍵確認點（皆以檔案對答案）
1. **價格用「收盤價」**，非均價/VWAP。證據：國巨(2327) 由 1140 崩到 699 的劇烈波動期，用收盤價逐日重建仍吻合到小數第 4 位；若用均價早已錯開。
2. **分母為「今日」融資餘額**，非前日餘額。用前日餘額時有系統性微差；改今日餘額後 2327 連續 6 日、1101 連續 14 日皆吻合到 0.0000。
3. **新融資買進以當日收盤入帳；融資賣出/現金償還不改變每股成本**（標準加權平均成本法）。

## 資料欄位對應
- 上市：TWSE `MI_MARGN`(selectType=ALL) → tables[1] 每檔：買進=idx2、今日餘額=idx6
- 上櫃：TPEx margin balance → tables[0] 每檔：資買=idx3、資餘額=idx6
- 收盤價：MI_INDEX(上市個股表 收盤價) / TPEx dailyQuotes(收盤 idx2)；單股用 MIS z

## 驗證結果
- 上市 8 檔 + 上櫃 4 檔、近 25 交易日全序列重建，**非事件日逐日誤差 = 0.0000**
- 上櫃用 TPEx 資買/資餘額 套同一公式亦吻合 → 公式universal
- 1101 近 14 日全序列最大誤差 0.00006（浮點捨入）

## 已知殘差：除權息調整（尚未完全還原）
- 3008、6488 等在 2026-06-18（除權息旺季）誤差一次性跳動（3008 +18.7、6488 −3.07），之後逐日被新買量稀釋衰減 → 除權息日的一次性調整（現金股利／配股）本遞迴未涵蓋。
- 影響幅度小（約 0.3~0.4%）且會自行收斂。要 100% 精準需在除權息日對成本做調整：
  - 除息：融資成本 −= 現金股利/股（融資戶領到的現金股利抵減融資金額）
  - 除權：依配股比例調整每股成本
- 除權息資料源：TWSE `TWT49U`（除權除息計算結果表）/ 除權息預告表。（端點格式待確認，後續補精準版）

## 實作策略（本專案採用）
- **種子**：`app/data/margin_cost_seed.json` = 檔案最後一日（2026-07-17）各檔融資成本（1744 檔），打包進 app。
- **滾動更新**：從種子日起，對每個交易日抓（買進、今日餘額、收盤）套上式，滾到最新交易日 → 得當前融資成本。
- **無種子的標的**（新上市/種子缺）：退回 N 日均價「簡易估計」，並標示 source。
- 維持率 = 收盤價 /（融資成本 × 0.6）× 100（與券商一致）。
