# F-012 融資清洗雷達（大盤指標 + 個股雙閘門）

## 投資命題
融資維持率是散戶槓桿痛苦指標。極端事件（如 2025/4 川普關稅）→ 融資被快速強制斷頭清洗
→ 維持率崩跌 → 恐慌性強制賣壓 = 階段性底部。分兩層抓：
- **大盤層（擇時）**：市場總體融資維持率 + MA20/60 → 判斷是否處於極端清洗低位階。
- **個股層（選股）**：抓「剛/快速」跌進低維持率者（新鮮清洗＝機會），排除「連續多日都低」的慢性套牢（價值陷阱）。

## 命題驗證（2025/4 川普關稅）
用 xlsx 成本+收盤 + 抓歷史融資餘額，實算大盤金額加權維持率（排除 ETF）：
| 日期 | 大盤維持率 |
|---|---|
| 2025-03-31 | 142.72 |
| 2025-04-07 | 133.57 |
| **2025-04-09** | **116.87**（全市場跌破 130 追繳線，恐慌底）|
| 2025-04-11 | 133.57 |
| 2025-05-15 | 163.62 |
→ 極端清洗低點與台股波段底吻合，命題成立。

## ① 大盤總體融資維持率
- 公式：`Σ(收盤×融資餘額) / Σ(融資成本×融資餘額×0.6) ×100`，**排除 ETF**（首碼 0）、91。
- 融資成本用加權滾動成本（F-011）；序列 = 打包歷史（`app/data/market_ratio_history.json`，近150交易日至 2026-07-17）+ 種子日後由 margin_cost 滾動補齊。
- MA20 / MA60；位階百分位（近120日）；清洗速度（5日變化）。
- 位階：`extreme_washout`(百分位≤10%且<MA60，價值浮現🟢) / `washing`(破MA20且下彎) / `overheated`(百分位≥85%且>MA60) / `normal`。

## ② 個股雙閘門（門檻 T = 130 追繳線）
每檔取「近期維持率序列」= bundle（`stock_ratio_recent.json`，種子前7日）+ rolled（種子後，margin_cost 滾動）：
- **閘門1 排除慢性套牢**：最近 5 日維持率全部 < 130 → 排除（`chronic_excluded`）。
- **閘門2 標記急殺清洗**：現值 < 130，且前 3 日曾 ≥ 130（新跨低），且近 1 日單日跌幅 ≥ 8（跨得快）→ `fresh_washout=true`，排到清單最上面。

## 端點
- `GET /api/market`：大盤指標（current/ma20/ma60/percentile/velocity_5d/level/series）
- `GET /api/alerts`：items 新增 `fresh_washout`；回應新增 `chronic_excluded`/`fresh_count`/`low_threshold`

## 資料檔（打包於 app/data）
- `margin_cost_seed.json`：融資成本種子（2026-07-17，1744 檔）
- `market_ratio_history.json`：大盤維持率日序列（150 點）
- `stock_ratio_recent.json`：個股近 7 日維持率（bootstrap 雙閘門）

## 更新方式
種子日之後，成本與大盤/個股維持率皆由 margin_cost 每日用 TWSE/TPEx 滾動補齊，MA 與雙閘門自動保持最新。日後拿到新的 xlsx 可一鍵重生種子與三個 bundle。
