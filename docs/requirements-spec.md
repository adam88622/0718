# 需求規格書 — margin-maintenance-tracker（台股融資維持率查詢工具）

## 專案名稱
margin-maintenance-tracker

## 專案根目錄
src/margin-maintenance-tracker/

## 專案概述
一個可獨立運作的台股融資維持率查詢工具網站。使用者搜尋單一股票代號後，系統自動抓取該股最新股價（盤中即時或盤後收盤）與融資餘額，並以「N 日均價」推估融資成本，計算並顯示該股「現價對應的融資維持率」；另提供選配的產業合計維持率功能。

**交付情境（重要）**：開發與驗證在開發者 macOS 機器完成；最終產品要交給另一台 **Windows** 電腦本地端使用。該 Windows 機器具備 Claude Code。交付物為「完整跨平台專案 + `BUILD_WINDOWS.md` 打包指令檔」，由對方 Windows 上的 Claude Code 讀指令自動安裝依賴並產出可安裝/可執行的成品。Windows 端**連網即時**向 TWSE 抓資料，不需離線快取。

## 專案類型
- 主要類型：web-fullstack
- 次要類型：data-science（資料抓取與指標計算邏輯）

## 技術選型
- 語言：Python（後端）+ HTML/CSS/JS（前端）
- 後端框架：FastAPI（TWSE API 的 CORS 代理層 + 計算邏輯層），uvicorn 啟動
- 前端：輕量單頁（原生 HTML + JS，或 Vite）；由 FastAPI 直接 serve 靜態檔，避免額外 Node 執行環境，利於跨平台與打包
- HTTP client：httpx（後端呼叫 TWSE）
- 資料源：TWSE 公開 API / OpenAPI（現價、日收盤序列、融資融券餘額）
- 跨平台：純 Python + 純前端，macOS 與 Windows 皆可執行；不使用平台專屬相依

## 功能清單

### F-001：股票搜尋（前端查詢介面）
- 輸入：股票代號（例：2330），可選：N 值調整輸入框（預設 20）
- 輸出：觸發後端查詢，顯示 loading；完成後顯示結果卡片
- 驗收條件：
  - 合法上市/上櫃代號（4 碼數字，91 開頭視為不支援並提示）可成功查詢
  - 不存在或格式錯誤代號顯示明確錯誤，不崩潰
  - 查詢中呈現 loading，避免重複送出

### F-002：現價抓取（盤中即時 / 盤後收盤）
- 輸入：股票代號
- 輸出：現價、資料時間戳、價格類型標記（"即時" / "收盤"）
- 驗收條件：
  - 交易時段（09:00–13:30 台北）回傳當下最新成交價，標記「即時」
  - 非交易時段回傳最近交易日收盤價，標記「收盤」
  - TWSE 無回應或當日無成交，回傳「無資料」狀態而非中斷

### F-003：N 日均價計算（融資成本推估）
- 輸入：股票代號、N（正整數，預設 20）
- 輸出：N 日均價、實際取用交易日區間（起訖）、實際筆數
- 驗收條件：
  - N=20 時為最近 20 個有效交易日收盤價算術平均
  - 調整 N 後重查結果更新
  - 歷史天數不足 N，以實際天數計算並標註「資料不足 N 日，以 X 日計算」

### F-004：融資餘額顯示
- 輸入：股票代號
- 輸出：融資餘額張數、資料日期
- 驗收條件：
  - 顯示最近一交易日融資餘額張數
  - 僅供顯示與產業合計用，不影響個股維持率公式
  - 資料缺漏顯示「無資料」而非報錯

### F-005：個股融資維持率計算
- 公式：`維持率 = 現價 / (N日均價 × 0.6) × 100`（融資成數固定 0.6）
- 輸出：維持率（%，小數 1~2 位）
- 驗收條件：
  - 與手動試算一致
  - N 日均價為 0 或缺值時不做除法，顯示「無法計算」而非 Infinity/NaN
  - 前端顯示公式使用的現價、N日均價、融資成數三值供核對
  - 顯示維持率警戒（如 < 130% 標紅提示追繳門檻）

### F-006：查詢結果整合呈現（前端結果卡片）
- 輸出：股票代號/名稱、現價（即時/收盤標記）、N日均價（區間）、融資餘額（日期）、維持率（大字醒目）、資料來源與時間戳
- 驗收條件：
  - 所有數值標註來源（TWSE）與擷取/計算時間
  - 盤中/盤後以標籤區分價格類型
  - 任一子資料失敗，該欄獨立顯示「無資料」，不影響其餘欄位

### F-007（選配）：產業合計維持率計算
- 公式：`Σ(收盤價×資餘) / Σ(N日均價推估×資餘×0.6) × 100`
- 輸出：上市合計維持率、上櫃合計維持率，各附成分股數
- 驗收條件：
  - 排除 91 開頭標的
  - 上市/上櫃分開計算與顯示
  - 缺資料個股從加總排除並註明「N 檔已排除」
  - 選配，不影響 MVP 主流程

### F-008：一鍵啟動（開發端獨立運作）
- 輸入：啟動指令（`uv run` / 啟動腳本）
- 輸出：本機服務啟動（前端網址 + 後端 API）
- 驗收條件：
  - 依 README 單一指令即可本機開啟並使用完整功能
  - 無需第三方帳號或金鑰（TWSE 公開資料）

### F-009：Windows 交付與打包（給對方 Claude 執行）
- 描述：產出讓 Windows 端 Claude Code 一鍵打包的完整交付物。
- 輸出：
  1. 完整跨平台專案原始碼（可直接於 Windows 執行）
  2. `BUILD_WINDOWS.md`：步驟化指令，指引 Windows 上的 Claude Code 建立虛擬環境、安裝依賴、以 PyInstaller 產出 onefile `.exe`（後端 + 內嵌前端），並選配以 Inno Setup 產出安裝程式
  3. Windows 啟動輔助：打包後 `.exe` 執行時自動啟動本機服務並開啟預設瀏覽器
  4. `requirements.txt` / `pyproject.toml` 明確鎖定依賴
- 驗收條件：
  - 專案於 macOS 開發機驗證可完整跑通（現價/N日均價/融資餘額/維持率）
  - `BUILD_WINDOWS.md` 指令自足、可被 Claude Code 逐步執行，無需人工補資訊
  - 程式不含 macOS 專屬路徑或指令（跨平台安全）
  - 明確說明：Windows `.exe` 需在 Windows 上打包（Mac 無法交叉編譯），本機交付僅提供原始碼與指令

## 非功能需求
- **獨立運作**：除 TWSE 公開資料源外無外部服務依賴，前後端自帶
- **CORS 代理**：前端不得直接呼叫 TWSE，一律經 FastAPI 後端代理
- **盤中/盤後行為差異**：依台北時間 09:00–13:30 判斷即時/收盤，前端明確標示
- **資料來源與時間戳標註**：所有數值標註來源（TWSE）與擷取/計算時間
- **容錯性**：任一 TWSE 源異常時優雅降級（欄位顯示「無資料」），不得整體中斷或 500 外洩
- **跨平台**：macOS 開發、Windows 執行皆可；純 Python + 純前端
- **一鍵啟動**（開發端）+ **一鍵打包**（Windows 端，見 F-009）

## 邊界條件與限制
- 免費融資融券資料僅「張數」無「金額」，融資成本一律以 N 日均價推估（非真實成本），UI 需以說明文字告知
- 產業分類若 TWSE 無標準化對照，需另維護對照表（選配實作細節）
- 91 開頭代碼（權證/牛熊證）一律排除
- N 值上下限（最小 1、最大不超過歷史天數）由實作設定合理範圍
- **跨平台編譯限制**：PyInstaller 無法跨平台，Windows `.exe` 必須在 Windows 產出

### F-010：全市場融資維持率警示清單（後續追加，已實作）
- 描述：一次掃描全市場「有融資餘額」的上市＋上櫃股票，計算每檔維持率並依由低到高排序，分區段色標，供使用者找出即將跌破追繳線的標的。呈現於單頁下方區塊。
- 輸入：N（均價天數，預設 20）；前端門檻篩選（<130 / <150 / <200 / 全部）
- 輸出：`GET /api/alerts?n=20` 回 items（code/name/market/price/n_day_avg/avg_days/margin_lots/ratio/band/adjusted）依 ratio 升序 + bands 門檻說明 + 統計（count/excluded/price_as_of/margin_as_of）
- 資料源：融資 universe = MI_MARGN(上市)+TPEx margin(上櫃)；N日均價 = 全市場單日收盤批次端點 MI_INDEX(上市)+dailyQuotes(上櫃) 抓 N 天組矩陣
- 驗收條件：
  - 排除 91 開頭；有融資餘額才納入
  - 分色門檻：<130 danger / 130~150 warn1 / 150~166.67 warn2 / ≥166.67 safe
  - 依維持率升序（最危險在前）
  - **除權/分割還原**：近 N 日收盤出現 >35% 跳空時只取事件後連續段計算均價並標記 adjusted，避免未還原價假警報
  - 效率：批次端點抓 N 天（非逐檔）；歷史收盤快取；整份結果後端快取 300 秒
  - 全程容錯，個別市場/個股失敗只計入 excluded 不影響整體
